# PLITAP · Узел сети

Программа независимого участника сети и компоненты поддержания распределённого состояния.

**Этап:** Опубликована структура направления. Реализация и содержательные материалы будут добавляться отдельными изменениями.

[Карта проекта](https://github.com/Plitap/Plitap/blob/main/REPOSITORIES.md) · [Общие правила участия](https://github.com/Plitap/.github/blob/main/CONTRIBUTING.md)

## Назначение

- Проработка ролей узла, его запуска, настройки и наблюдения за работой.
- Хранение, синхронизация и восстановление доступных сетевых данных.
- Реализация выбранных правил проверки и согласования состояния.

## Границы направления

Узел не является обязательным центральным сервером PLITAP. Хранение или ретрансляция не дают полномочий на чужие плитки и не означают автоматического участия в согласовании. Состав ролей и механизм финальности ещё проектируются. Для проверок узел использует [core](https://github.com/Plitap/core), для обмена — [network](https://github.com/Plitap/network).

## Структура

| Раздел | Назначение |
|---|---|
| [`src/`](src/) | Исходный код программы узла и его компонентов; подробная модульная архитектура определяется после проектирования. |
| [`tests/`](tests/) | Внутренние проверки узла, синхронизации, восстановления и отказов. |
| [`docs/`](docs/) | Проектирование и эксплуатационные инструкции программы узла. |
| [`docs/roles/`](docs/roles/) | Назначение ролей узла, их возможности и ограничения. |
| [`docs/state/`](docs/state/) | Разделение реестра состояния и содержимого; варианты согласования и финальности. |
| [`docs/storage/`](docs/storage/) | Репликация, доступность, хранение зашифрованных данных и восстановление копий. |
| [`docs/operations/`](docs/operations/) | Запуск и обслуживание независимого узла после появления реализации. |

Каждый раздел сейчас содержит README с его назначением. Названия разделов не обозначают готовую функцию или выбранную технологию.

## Участие

Вопросы об этом направлении и конкретные задачи — в [Issues](https://github.com/Plitap/node/issues). Общие идеи — в [обсуждениях PLITAP](https://github.com/Plitap/Plitap/discussions).

Предложение должно объяснять задачу, ожидаемый результат и связанные компоненты. Рабочее обсуждение, принятое правило и опубликованная реализация имеют разные статусы.

## Условия использования

Лицензии для кода, спецификации и визуальных материалов определяются отдельно. См. [статус лицензирования](https://github.com/Plitap/.github/blob/main/LICENSING.md).
