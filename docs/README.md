# Узел сети · `docs/`

Проектирование и эксплуатационные инструкции программы узла.

**Статус:** обозначено место будущих материалов. Код, результаты проверок и нормативные определения здесь пока не опубликованы.

## Подразделы

- [roles/](roles/) — Назначение ролей узла, их возможности и ограничения.
- [state/](state/) — Разделение реестра состояния и содержимого; варианты согласования и финальности.
- [storage/](storage/) — Репликация, доступность, хранение зашифрованных данных и восстановление копий.
- [operations/](operations/) — Запуск и обслуживание независимого узла после появления реализации.

При добавлении материалов указывайте их версию, назначение и способ проверки. Исследовательские варианты отмечайте как предложения.
