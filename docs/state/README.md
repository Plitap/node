# Узел сети · `docs/state/`

Разделение реестра состояния и содержимого; варианты согласования и финальности.

**Статус:** обозначено место будущих материалов. Код, результаты проверок и нормативные определения здесь пока не опубликованы.

При добавлении материалов указывайте их версию, назначение и способ проверки. Исследовательские варианты отмечайте как предложения.
